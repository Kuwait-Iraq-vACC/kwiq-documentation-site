# Alias View

The alias file describes all the . (dot) shortcuts for use in EuroScope.

The alias file can be located at `ORBB/OKAC > Alias > alias.txt`. Controllers may choose to make edits or personalise the file. 

!!! warning "Caution"
    Note that when updating your sector file, the alias file will be overwritten.

## Editing your alias file

The file is split up into different sections in order to categorise them together and make it easier to read. Categories are shown as `;*** General ***` with . (dot) shortcuts being shown as `.<alias name> <alias value>`.

Any alias' can be edited with no restrictions. Once you have finished editing the alias file, they may be reloaded by:

> Open SCT > Load Aliases > Navigating to your alias file as above
