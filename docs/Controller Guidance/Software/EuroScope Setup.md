## KWIQ Controller Plugin
The OKAC and ORBB sector files load the [KWIQ Controller Plugin](../KWIQ%20Controller%20Plugin/index.md) for you. The first time EuroScope starts with it, you are asked to download its components and connect your myKWIQ API key. See the [user guide](../KWIQ%20Controller%20Plugin/index.md) for how to set it up.
