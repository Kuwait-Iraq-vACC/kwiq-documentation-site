vacs is an open source communication system for controller-to-controller coordination on VATSIM.

Whenever you are logged on to a Kuwait-Iraq vACC position, you **must be available for coordination on vacs or Discord**. Being available on both is preferred. See [PRC-KWIQ-26-001](../Procedure%20Updates/Updates/posts/prc-kwiq-26-001.md).

!!! tip
    EuroScope's built-in coordination functions (COPX, COPN, PEL, XFL) are always preferred over voice or text coordination. Neighbouring vACCs may not be using vacs. If they aren't, use the built-in functions, EuroScope private chat or other agreed means.
