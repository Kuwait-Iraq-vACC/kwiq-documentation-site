## Summary

From **AIRAC 2611 (29/10/2026)**, the logon callsign for the Kirkuk Sector of Baghdad Approach changes.

| Position      | Old Logon Callsign | New Logon Callsign | Frequency |
| ------------- | ------------------ | ------------------ | --------- |
| Kirkuk Sector | ~~KIR_APP~~        | **KRK_APP**        | 127.700   |

The radio callsign (**Baghdad Approach**), frequency, airspace and the aerodromes covered (ORBM, ORER, ORKK, ORSJ) are **unchanged**.

!!! note
    The Kirkuk VOR/DME identifier remains **KIR** (111.200). Only the logon callsign has changed.

## Controller Actions

- From 29/10/2026, log on using **KRK_APP** only.
- Departure releases from ORER, ORKK and ORSJ are now coordinated with **KRK_APP**.
- Baghdad Control North (BN) hands off arrivals to, and receives departures from, **KRK_APP**.

## Documentation Status

The Baghdad Approach, Kirkuk Sector, Baghdad Sector and BN pages, and the ORER, ORKK and ORSJ aerodrome pages, have been updated to reflect this change.
